## Ringkasan Singkat

Praktikum ini membandingkan performa FNN dengan aktivasi ReLU, Tanh, dan Sigmoid pada dataset `make_moons` dengan hidden size 4 dan 16. Dengan protokol 200 epoch, SGD, learning rate 0,05, dan batch size 32, model ReLU dengan hidden size 16 memperoleh validation accuracy 92,50% dan validation loss 0,2092. Model tersebut juga memiliki train accuracy 93,06% dengan waktu training sekitar 3,30 detik. Berdasarkan validation loss terendah, model ReLU dengan hidden size 16** dipilih sebagai model final. Pada test set, model memperoleh accuracy 90,83% dan loss 0,2234.

## 1. Tujuan dan Hipotesis

### 1.1 Tujuan

1. Membandingkan performa FNN dengan fungsi aktivasi ReLU, Tanh, dan Sigmoid pada dataset `make_moons`.
2. Menganalisis pengaruh hidden size 4 dan 16 terhadap validation loss dan validation accuracy.
3. Menentukan model terbaik berdasarkan validation loss terendah dan mengevaluasi performanya pada test set.


### 1.2 Hipotesis sebelum eksperimen


| Perbandingan | Prediksi | Alasan teknis |
|---|---|---|
| Hidden size 4 vs 16 | Hidden size 16 diperkirakan menghasilkan validation loss lebih rendah daripada hidden size 4 | Jumlah neuron tersembunyi yang lebih besar memberikan kapasitas model lebih tinggi untuk menangkap pola nonlinear pada dataset `make_moons`. |
| ReLU vs Tanh | ReLU diperkirakan menghasilkan validation loss lebih rendah daripada Tanh | ReLU tidak mengalami saturasi pada input positif sehingga gradien cenderung lebih mudah mengalir saat proses pembelajaran. |
| ReLU vs Sigmoid | ReLU diperkirakan menghasilkan validation loss lebih rendah dan proses pembelajaran lebih efektif daripada Sigmoid | Sigmoid lebih mudah mengalami saturasi yang dapat menyebabkan gradien menjadi kecil, sedangkan ReLU memiliki bentuk yang lebih sederhana dan tidak jenuh pada input positif. |

## 5. Analisis dan Pembahasan

### **5.1 Perbandingan dengan Hipotesis**

| Unsur | Isi |
|---|---|
| Klaim | Hidden size 16 secara konsisten menghasilkan validation loss lebih rendah dibanding hidden size 4, untuk ketiga aktivasi. |
| Bukti | Pada ReLU, validation loss turun dari 0,3060(hidden 4) menjadi 0,2092 (hidden 16). Pada Tanh, validation loss turun dari 0,3264 menjadi 0,2453, sedangkan pada Sigmoid hanya turun dari 0,3261 menjadi 0,3228. ReLU-16 juga memiliki validation loss terendah, yaitu 0,2092. |
| Penalaran | Hidden size yang lebih besar memberikan kapasitas model yang lebih tinggi untuk menangkap pola nonlinear pada `make_moons`. ReLU juga tidak mengalami saturasi pada input positif sehingga proses pembelajaran dapat berlangsung lebih efektif dibandingkan aktivasi yang lebih mudah mengalami saturasi seperti Sigmoid. |
### **5.2 Run Terbaik dan Run Terburuk**

| Unsur | Isi |
|---|---|
| **Klaim** | Run terbaik adalah ReLU dengan hidden size 16, sedangkan run terburuk berdasarkan validation loss adalah Tanh dengan hidden size 4. |
| **Bukti** | ReLU-16 memperoleh validation loss 0,2092 dan validation accuracy 0,9250, sedangkan Tanh-4 memperoleh validation loss 0,3264 dan validation accuracy 0,8583. |
| **Penalaran** | ReLU-16 memiliki kapasitas model yang lebih besar untuk mempelajari pola nonlinear dataset. Sebaliknya, Tanh-4 memiliki kapasitas yang lebih terbatas sehingga pola `make_moons` tidak dapat dipelajari sebaik konfigurasi dengan hidden size 16. |

### **5.3 Trade-off Akurasi, Parameter, dan Waktu**

| **Penalaran** | Jumlah parameter memengaruhi kapasitas model, tetapi waktu training juga dipengaruhi oleh faktor lain seperti proses komputasi dan kondisi runtime. Oleh karena itu, pada eksperimen ini waktu training tidak menunjukkan hubungan langsung dengan jumlah parameter. |

## 7. Kesimpulan dan Keterbatasan

### 7.1 Kesimpulan

Praktikum ini berhasil membandingkan performa FNN dengan aktivasi ReLU, Tanh, dan Sigmoid pada hidden size 4 dan 16 menggunakan dataset make_moons. Berdasarkan validation loss terendah, konfigurasi ReLU dengan hidden size 16 dipilih sebagai model final dengan validation loss 0,2092 dan validation accuracy 92,50%. Pada test set, model tersebut memperoleh accuracy 90,83% dengan loss 0,2234. Hasil ini menunjukkan bahwa konfigurasi ReLU-16 mampu mempelajari pola nonlinear pada dataset make_moons dengan performa yang cukup konsisten pada data validation dan test.

### 7.2 Keterbatasan

- Jumlah seed hanya satu. Setiap konfigurasi hanya dijalankan dengan satu SEED, sehingga hasil yang diperoleh belum menunjukkan variasi performa model terhadap perubahan inisialisasi. Hal ini membatasi generalisasi hasil eksperimen.
- Ruang eksperimen terbatas. Perbandingan hanya dilakukan pada tiga fungsi aktivasi, yaitu ReLU, Tanh, dan Sigmoid, serta dua hidden size, yaitu 4 dan 16, dengan learning rate 0,05 dan 200 epoch yang tetap. Oleh karena itu, konfigurasi lain belum dapat dibandingkan.

### 7.3 Tindak lanjut

Jika tersedia tambahan waktu atau komputasi, eksperimen yang paling bernilai adalah mengulangi setiap konfigurasi dengan beberapa seed kemudian menghitung rata-rata dan standar deviasi validation loss serta validation accuracy. Hal ini dapat menunjukkan apakah performa ReLU-16 yang memperoleh validation loss 0,2092 konsisten atau hanya dipengaruhi oleh satu inisialisasi tertentu.
